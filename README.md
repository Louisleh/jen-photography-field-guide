# Jen’s Photography Field Guide

A complete 16-session course for the Fujifilm X-T5, XF16–50mm F2.8–4.8 R LM WR, and Godox TT350F. Start with a window-light portrait, then learn light, composition, focus, movement, travel, low light, flash, color, editing and a small final collection.

## Open and use

Open `index.html` in a current browser. The downloaded HTML contains all lessons, photographs, CSS, diagrams and JavaScript. No server, installation, account, font download or network connection is required. On a phone, the hosted HTTPS link is usually easiest; file managers may preview downloaded HTML without running interactions, so open it in a browser when possible.

Choose **Start here**. Each lesson has an outcome, real photo references, plain-language explanation, exact equipment actions, suggested starting settings, a 15–30-minute assignment, one-variable comparison with exposure caveats, success criteria, three mistakes/fixes, a decision quiz, first adjustment and optional deeper explanation. Allow roughly 10–15 minutes with the camera beside you for reading, inspecting examples and trying controls. Reading silently without doing the checks is faster. This is a beginner fast track, not a promise of professional mastery.

Use **Mark complete** and **Next lesson**. The welcome screen's Continue link returns to the last lesson you opened. Completion can be undone. The guide keeps your place and checklist/weak-area selections in this browser only; it does not synchronize devices. Export progress before clearing browser data or changing devices. Import validates the small JSON file and asks before replacing current progress. Reset asks for confirmation. If storage is blocked, the course still works for the current visit and can export progress.

Field tools include five button-controlled schematics, symptom troubleshooting, a four-week planner, an eight-photo checklist with a three-image story, and four separate print references. Use each reference's Print button, not the general page print command, to print only that reference. The field sheet was tested as one page on A4 and US Letter with browser headers/footers off; print settings and browser fonts can change pagination. The scenario table uses landscape pages. Use 100% scaling and the document's page size.

JavaScript-disabled mode leaves the lesson text, embedded photographs, assignments, explanatory quiz answers and references readable. Controls requiring JavaScript are unavailable; expandable native details supply static comparison explanations. The course does not upload photos, offer automatic critique or call an AI service.

## Equipment checks and limitations

Equipment instructions were checked against official Fujifilm and Godox documentation on **2026-09-12 PT**. These are documentation checks, not hands-on testing with Jen's physical camera, lens or flash. Installed firmware and customized control assignments are unknown. Follow the display and the official current manual if a custom dial behaves differently.

- **Exact lens:** automatic aperture is the separate aperture-mode switch at A, not an A position on the ring. For manual aperture select the aperture symbol, then turn the unmarked aperture ring and read the display. Widest aperture is f/2.8 at16mm and f/4.8 at50mm. Intermediate maximum apertures are not invented. f/5.6 is available throughout.
- **Close focus:** 0.24m is measured from the focal plane/sensor, not the lens front. Maximum magnification is0.3× at the tele end. Marketing equivalent-magnification language is not treated as true0.5× macro.
- **Auto ISO:** the camera can fall below the requested minimum shutter when the maximum ISO would otherwise leave underexposure. A suggested ISO profile is not labeled a factory default.
- **Focus:** frontS/C/M is separate from exposureP/S/A/M. Human face/eye and ANIMAL detection disable each other; switch back for portraits. Detection does not guarantee focus on the intended eye.
- **Shutter and flash:** Fujifilm documents normal sync at1/250s or slower. Basic lessons use mechanical shutter, single frame,1/125s. Full electronic shutter does not fire flash in ordinary photography (the manual's specialist pixel-shift exception is outside this course). E-front curtain is not conflated with full electronic shutter.
- **Godox controls:** MODE selectsTTL orM; FEC uses SET → select dial → SET. Manual flash output ranges1/1–1/128, not the generic Fujifilm menu's larger range. Red ready indicator and pauses between frames matter. The guide does not promise burst recycling or guaranteed motion-freezing.
- **Compatibility:** the older bundled TT350F manual lists older bodies. Godox's current official camera compatibility chart separately lists X-T5 in the Fujifilm flash family that includesTT350F. This supports documented compatibility but is not a claim of hands-on validation or a specific installed firmware version.
- **Firmware:** the checked X-T5 release page displayed4.31; versions will change.4.00 added REALA ACE.4.30 changed phone pairing and removed legacy WIRELESS COMMUNICATION menu entries; it ended the old Camera Remote iOS route. The guide uses current XApp/SD-reader alternatives and does not make a firmware update a prerequisite for the first photograph.
- **Flash examples:** real indoor portraits accompany the lessons and schematics. We did not obtain a controlled no-flash/direct/bounced sequence. No unrelated photographs are presented as controlled before/after results; Jen makes her own matched test. Diagrams explain geometry or a trade-off, not numerical exposure or measured X-T5 output.
- **Safety and consent:** use willing people, safe movement and paths, avoid close direct flashes into eyes, keep the flash dry, do not dismantle it, and pause for heat/readiness. Camera stabilization reduces camera shake, not moving subjects. The course makes no promise that small flashes can overpower every room or the sun.
